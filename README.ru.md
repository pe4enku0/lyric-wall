# Lyric Wall

[English](README.md) · **Русский**

Музыкальные обои для macOS и Windows: что сейчас играет в Spotify и синхронный текст песни прямо на рабочем столе.
Системные обои не меняются: обои — это собственное окно приложения под всеми окнами
(на Windows — за иконками рабочего стола, как у Wallpaper Engine / Lively).

Приложение работает на русском и английском (меню в трее → Language / Язык).

## Скачать

- **Последняя сборка:** вкладка **Actions** → верхняя зелёная сборка → внизу блок **Artifacts** →
  `windows-exe` (установщик для Windows) или `mac-app` (приложение для Mac). Скачивается zip, внутри — файл.
- **Версии:** раздел **Releases** справа на странице репозитория.
  Новая версия появляется, когда отправлен тег: `git tag v0.1.0 && git push --tags`.

Сборки не подписаны платным сертификатом:
- Windows покажет «Windows защитила ваш компьютер» → **Подробнее** → **Выполнить в любом случае**.
- macOS может не открыть приложение → **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.

## Как пользоваться

- **Запуск** включает обои и не открывает никаких окон: приложение живёт только **в трее**
  (Windows, у часов — возможно, под стрелкой **^**) или **в строке меню** (Mac). На панели задач и в Dock его нет.
  При первом запуске появится короткое уведомление об этом.
- **Значок в трее / строке меню:** открыть Lyric Wall, обои вкл/выкл, пауза, следующий трек, настройки,
  режим обоев (Windows), язык, запуск при входе, лог, выход.
- **Окно управления** (трей → «Открыть Lyric Wall» или повторный запуск приложения): что играет, кнопки,
  обои вкл/выкл и сколько процессора они занимают, язык, запуск при входе, лог, выход.
  Окно можно закрыть — обои продолжат работать.
- **Настройки** (трей → «Настройки…» или «Фон и снежинки…» в окне управления): готовые фоны, цвет из обложки,
  размытая обложка, своя картинка (копируется в папку данных приложения), размытие и затемнение картинки,
  скорость и количество снежинок, виджет «Звук», плавность (30 / 20 / 15 кадров в секунду), пауза от батареи.
  Всё применяется сразу и сохраняется.

### Кнопки на обоях

| Кнопка | Что делает |
|---|---|
| ⏮ ⏯ ⏭ | предыдущий трек, пауза / играть, следующий трек |
| полоска прогресса | перемотка в это место песни |
| полоска громкости · динамик | громкость · выключить / включить звук (на Mac — громкость Spotify, на Windows — системная) |
| «Перемешивание» | перемешивание вкл / выкл |
| обложка | открыть Spotify |
| белая кнопка текста | скрыть / показать текст песни |
| устройство («MacBook» / «Компьютер») | открыть системные настройки звука |
| «…» | открыть окно управления |
| ★ | лайк / убрать лайк (после входа в Spotify; закрашена, если трек в «Любимых») |

Сами обои лежат под иконками рабочего стола и клики не получают. Поверх кнопок стоят невидимые области для
нажатий — **позади всех остальных окон**, как виджеты рабочего стола: если обои закрыты окнами, клики достаются
окнам; на открытом рабочем столе работают кнопки. Клики рядом с кнопками уходят рабочему столу, как обычно.

- **macOS:** маленький системный помощник (`mac-helper/ClickLayer.swift`) ставит над кнопками неактивирующие
  панели. macOS отдаёт клики только обычным окнам, а обычное окно приложения при нажатии делает приложение
  активным — и macOS возвращает окна, которые раздвинула, чтобы показать рабочий стол. Эти панели ничего не
  активируют, остаются на месте при показе рабочего стола и не участвуют в переключении окон.
- **Windows:** невидимое окно над иконками ловит клики только когда курсор над кнопкой (приложение проверяет
  положение курсора 20 раз в секунду). Пока открыта игра или окно на весь экран, оно убирается.

## Аккаунт Spotify (необязательно): «Дальше» и лайки

Вход в Spotify (Настройки → «Аккаунт Spotify») показывает на обоях следующие 3 трека, а ★ ставит лайк текущему треку.
Для этого нужно своё бесплатное приложение на developer.spotify.com (Spotify Web API):

1. Открой [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard) и войди.
2. **Create app** → любое название и описание; **Redirect URIs**: `http://127.0.0.1:43821/callback`; отметь **Web API**; сохрани.
3. Открой **Settings** приложения, скопируй **Client ID** в Lyric Wall → **Войти в Spotify** → разреши в браузере.

Правила Spotify с февраля 2026: такие приложения работают, только пока у **владельца есть Spotify Premium**, и не больше
чем для **5 пользователей** — друзей добавляют в **User Management** по их email в Spotify. Вход идёт через PKCE (без
секретного ключа); данные входа хранятся зашифрованными (Связка ключей macOS / защита данных Windows) и не пишутся в лог.

## Spotify

- **macOS:** данные берутся из приложения Spotify через AppleScript. При первом запуске macOS спросит,
  можно ли Lyric Wall управлять Spotify. Если ответили «нет»: Системные настройки → Конфиденциальность
  и безопасность → Автоматизация → Lyric Wall → включить Spotify.
- **Windows:** данные берутся из системного медиаплеера Windows (как в меню громкости).
  Входить в Spotify не нужно. Громкость самого Spotify там недоступна, поэтому показывается системная.
  Если Windows не отдаёт обложку, она берётся из открытого каталога iTunes по артисту и названию.

## Текст песни и производительность

- Синхронный текст из [LRCLIB](https://lrclib.net) идёт за песней с размытием и фокусом. Поиск и база LRCLIB
  опрашиваются одновременно, поэтому текст обычно появляется за 0,1–0,3 с. Найденные тексты сохраняются в папке
  данных приложения; если синхронного текста нет, обычный текст прокручивается вместе с песней.
- Обои рисуются не чаще 30 кадров в секунду (или 20 / 15 в настройках), засыпают, когда ничего не движется
  (музыка на паузе), и полностью останавливаются, когда экран заблокирован, компьютер спит, открыта игра или окно
  на весь экран (Windows) или — если включено в настройках — при работе от батареи.
- В окне управления видно, сколько процессора занимает приложение. На MacBook: около 1% одного ядра, когда музыка
  на паузе; когда музыка играет и обои полностью видны — около 34% при 30 кадрах и 21% при 15 кадрах.

## Лог

Всё важное пишется в `lyric-wall.log` в папке данных приложения (трей → **Открыть лог**): запуск (система, экран),
как встало окно-обои, треки и команды Spotify, тексты, паузы (блокировка, игра, батарея), нажатия кнопок,
ошибки в любом окне и упавшие процессы. Лог хранится только на компьютере; больше 1 МБ — переносится
в `lyric-wall.log.old`.

Папка данных приложения: Mac `~/Library/Application Support/Lyric Wall/`, Windows `%APPDATA%\Lyric Wall\`.

## Проверка на Windows после установки

1. Установщик работает без прав администратора; ярлык «Lyric Wall» появляется на рабочем столе и в «Пуске».
2. Запусти: окно не открывается, приходит уведомление «Lyric Wall работает», значок — в трее (возможно, под **^**).
3. Обои **за иконками** рабочего стола, иконки и клики по рабочему столу работают как раньше.
4. Включи музыку в Spotify: трек, обложка, бегущая полоска и синхронный текст.
5. Цифра громкости совпадает с громкостью Windows, столбики прыгают в такт музыке.
6. Кнопки на обоях: ⏯, ⏭, перемотка, громкость, «Перемешивание» работают, курсор над ними становится «рукой».
7. Запусти игру на весь экран: в логе `Render paused (+fullscreen)`, FPS не ниже, чем без приложения.
8. Трей → «Обои» выкл.: возвращаются обычные обои Windows.
9. Если обои чёрные или их нет: трей → «Режим обоев» → «Под всеми окнами», и пришли лог.

## Запуск из исходников (Mac)

```bash
cd ~/lyric-wall
npm install      # один раз, после скачивания проекта
npm start        # запустить обои (иконка появится в строке меню)
npm run window   # показать обои в обычном окне — удобно смотреть на дизайн
```

На macOS `npm start` ещё собирает помощник для кнопок (`mac-helper/ClickLayer.swift`); для этого нужны
Xcode Command Line Tools (`xcode-select --install`). Без них кнопки работают через более простой слой.

## Как устроен проект

| Папка | Что внутри |
|---|---|
| `main/` | главный процесс: окна, трей, плеер, тексты, Spotify Web API, настройки, лог, языки, слой для кликов |
| `renderer/` | интерфейс обоев (внешний вид из `mockup.html`), окна управления и настроек |
| `adapters/` | `mac.js` и `win.js` (+ `win-media.ps1`); на каждой системе загружается только свой файл |
| `mac-helper/` | помощник для macOS, благодаря которому нажимаются кнопки на обоях |
| `scripts/` | скрипт сборки помощника |
| `locales/` | тексты интерфейса на английском (`en.json`) и русском (`ru.json`) |
| `assets/` | иконка приложения (`icon-mac.png`, `icon-win.png`), иконки строки меню и трея |
| `mockup.html` | исходный макет дизайна |
