# Lyric Wall

[English](README.md) · **Русский**

Музыкальные обои для macOS и Windows: что сейчас играет в Spotify и синхронный текст песни прямо на рабочем столе.
Системные обои не меняются: обои — это собственное окно приложения под всеми окнами
(на Windows — за иконками рабочего стола, как у Wallpaper Engine / Lively).

Приложение работает на русском и английском (меню в трее → Language / Язык).

## Скачать

- **Последняя сборка:** вкладка **Actions** → верхняя зелёная сборка → внизу блок **Artifacts** →
  `windows-exe` (установщик для Windows) или `mac-app` (приложение для Mac). Скачивается zip, внутри — файл.
- **Версии:** раздел **Releases** справа на странице репозитория.
  Новая версия появляется, когда отправлен тег: `git tag v0.1.0 && git push --tags`.

Сборки не подписаны платным сертификатом:
- Windows покажет «Windows защитила ваш компьютер» → **Подробнее** → **Выполнить в любом случае**.
- macOS может не открыть приложение → **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.

## Spotify

- **macOS:** данные берутся из приложения Spotify через AppleScript. При первом запуске macOS спросит,
  можно ли Lyric Wall управлять Spotify. Если ответили «нет»: Системные настройки → Конфиденциальность
  и безопасность → Автоматизация → Lyric Wall → включить Spotify.
- **Windows:** данные берутся из системного медиаплеера Windows (как в меню громкости).
  Входить в Spotify не нужно. Громкость самого Spotify там недоступна, поэтому цифра скрыта.

## Запуск из исходников (Mac)

```bash
cd ~/lyric-wall
npm install      # один раз, после скачивания проекта
npm start        # запустить обои (иконка появится в строке меню)
npm run window   # показать обои в обычном окне — удобно смотреть на дизайн
```

При запуске приложения (или повторном клике по его иконке) открывается **окно управления**:
что играет, кнопки ⏮ ⏯ ⏭, обои вкл/выкл, язык, запуск при входе, лог, выход.
Окно можно закрыть — обои продолжат работать. Те же пункты есть в иконке в строке меню (Mac)
или в трее (Windows). При автозапуске после входа в систему окно не открывается.
Лог и настройки лежат в папке данных приложения:
Mac — `~/Library/Application Support/Lyric Wall/`, Windows — `%APPDATA%\Lyric Wall\`.

## Как устроен проект

| Папка | Что внутри |
|---|---|
| `main/` | главный процесс: окна, трей, плеер, настройки, лог, языки |
| `renderer/` | интерфейс обоев (внешний вид из `mockup.html`) и окно управления |
| `adapters/` | `mac.js` и `win.js` (+ `win-media.ps1`); на каждой системе загружается только свой файл |
| `locales/` | тексты интерфейса на английском (`en.json`) и русском (`ru.json`) |
| `assets/` | иконка приложения (`icon-mac.png`, `icon-win.png`), иконки строки меню и трея |
| `mockup.html` | исходный макет дизайна |
