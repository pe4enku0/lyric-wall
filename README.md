# Lyric Wall — музыкальные обои

Окно-обои для macOS и Windows: что играет в Spotify и синхронный текст песни прямо на рабочем столе.
Системные обои не меняются — обои это собственное окно приложения.

## Запуск на Mac (для разработки)

```bash
cd ~/lyric-wall
npm install      # один раз, после скачивания проекта
npm start        # запустить обои (иконка появится в строке меню)
npm run window   # показать обои в обычном окне — удобно смотреть на дизайн
```

Управление — через иконку в строке меню (Mac) или в трее (Windows):
обои вкл/выкл, пауза, следующий трек, запуск при входе, лог, выход.
Лог и настройки лежат в папке данных приложения:
Mac — `~/Library/Application Support/Lyric Wall/`, Windows — `%APPDATA%\Lyric Wall\`.

## Где скачать готовое приложение

- **Последняя сборка:** вкладка **Actions** → верхняя зелёная сборка → внизу блок **Artifacts** →
  `windows-exe` (установщик для Windows) или `mac-app` (приложение для Mac). Скачивается zip, внутри — файл.
- **Версии:** вкладка **Releases** (справа на главной странице репозитория).
  Новая версия появляется, когда отправлен тег: `git tag v0.1.0 && git push --tags`.

## Как устроен проект

| Папка | Что внутри |
|---|---|
| `main/` | главный процесс: окна, трей, системные вещи |
| `renderer/` | интерфейс обоев (внешний вид из `mockup.html`) |
| `adapters/` | отдельный код для `mac.js` и `win.js`; на каждой системе загружается только свой файл |
| `assets/` | иконки для строки меню и трея |
| `mockup.html` | исходный макет дизайна |
