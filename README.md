# Lyric Wall — музыкальные обои

Окно-обои для macOS и Windows: что играет в Spotify и синхронный текст песни прямо на рабочем столе.
Системные обои не меняются — обои это собственное окно приложения.

## Запуск на Mac (для разработки)

```bash
cd ~/lyric-wall
npm install      # один раз, после скачивания проекта
npm start        # открыть приложение
```

## Как устроен проект

| Папка | Что внутри |
|---|---|
| `main/` | главный процесс: окна, трей, системные вещи |
| `renderer/` | интерфейс обоев (внешний вид из `mockup.html`) |
| `adapters/` | отдельный код для `mac.js` и `win.js`; на каждой системе загружается только свой файл |
| `mockup.html` | исходный макет дизайна |

## Как отправить изменения на GitHub

cd ~/lyric-wall
